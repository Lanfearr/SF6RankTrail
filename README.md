# SF6RankTrail

> 实时追踪《街头霸王 6》LP / MR 分数变化与对局表现的 Windows 桌面应用。

当前版本：`1.2.0` · 平台：Windows 10/11 64 位 · 许可证：MIT

SF6RankTrail 通过 Capcom 官方 Buckler's Boot Camp 页面同步排位数据，在本地建立可查询的对战数据库，并提供会话统计、角色与对手分析、目标进度和趋势图表。所有数据保存在本机，不需要云服务。

## 功能概览

- **准实时同步**：登录 CAPCOM ID 后自动轮询对战记录，同步间隔可在 15–120 秒之间调整，默认 20 秒；每小时自动核对最近历史，补齐延迟上传的场次。
- **多账号追踪**：同时追踪自己和其他玩家的 CFN / short_id，随时切换当前账号。
- **对局去重与归档**：按账号 + Replay ID 去重，所有对局、分数点和会话保存在本地 SQLite 数据库。
- **会话统计**：自动按空闲时间切分会话，按最后一场角色计算净分；结束分只使用赛后观测，缺失显示 `—`，并展示胜负、MR/LP 净分、时长与 MR/LP 范围。
- **对战记录**：按 MR/LP、胜负、角色和日期筛选，查看每场对手、赛前分数与分数变化。
- **对手信息**：在对战详情页按赛季与角色查看本地交手记录（对手当时 MR/LP），并可按需从 Buckler 查询对手当前赛季或历史最高段位。
- **概览趋势图**：在概览页直接查看完整分数变化曲线，横轴为日期，支持 MR/LP、角色、时间范围与自定义日期筛选，图表下方带缩放条；点击对手头像可跳转到该场对战详情。
- **角色统计**：汇总各角色的对局数、胜率、当前 MR/LP 和最后对局时间。
- **对手分析**：按对手角色统计 matchup，支持点击表头排序，并按对手玩家名与 ID 追踪宿敌与近期胜负；点击宿敌可查看对手详情。
- **赛季报告**：按赛季或月份汇总对局数、胜率及 MR/LP 范围。
- **目标与趋势**：设置账号级 MR/LP 目标，查看目标进度、近期场均、连胜/连败和近 12 周活跃度。
- **Mini / Pro 图表**：Mini 面板显示当前分数与会话数据；Pro 图表展示最近 20 场的 MR/LP 趋势，支持角色筛选和缩放。
- **导出与恢复**：支持对战 CSV、完整 JSON、JSON 恢复和 SQLite 数据库备份。
- **自动备份**：默认每 24 小时备份数据库，保留最近 14 份。
- **同步诊断**：查看登录状态、最近同步时间、数据量、当前会话与最近同步事件，可手动重新扫描当前账号最近历史补齐遗漏对局，并在浮动提示中查看扫描场次、可查询日期范围与失败原因。
- **窗口自定义**：图表窗口支持透明、置顶、不透明度以及 Mini / Pro 默认模式设置。

## 图表窗口

### Mini

- 显示当前 MR 或 LP，可随时切换。
- 显示本会话净上分、胜负场次、胜率和当前角色。
- 支持手动刷新当前会话。
- 默认置顶并透明显示，适合放在游戏画面旁边。

### Pro

- 展示最近 20 场排位对局，支持 MR / LP 切换。
- 支持按角色筛选，默认选中最近使用的角色。
- 图表以对局为单位编号（`#1`、`#2`……），横轴为“场次”。
- 对手头像与单场分数变化直接标记在对应比赛点上，点击头像可在主窗口打开该场对战详情。
- 支持鼠标滚轮/拖动缩放，缩放范围在数据刷新后保持。
- 图表只展示真实比赛点；当前 LP/MR 仍取账号最新快照。

### 窗口设置

- 可设置图表窗口默认模式（Mini / Pro）。
- 可开启或关闭窗口置顶。
- 可将不透明度调整为 20%–100%。
- Mini 与 Pro 分别记住窗口位置和尺寸。

## 快速开始

1. 运行安装包 `SF6RankTrail-v<版本>-x64.exe`，按向导完成安装。
2. 启动应用，点击“登录 CAPCOM ID”。
3. 首次登录会打开普通 Chrome 窗口，请手动完成 CAPCOM ID 登录及人机验证。
4. 登录成功后应用会保存会话并自动开始同步。
5. 在“设置”中添加其他 CFN / short_id 账号，或调整同步间隔与图表选项。
6. 点击“图表窗口”打开 Mini / Pro 面板。

> 首次登录需要用户手动操作，应用不会代替用户输入账号密码。

## 数据来源与同步机制

- 数据来自 Capcom 官方 Buckler's Boot Camp 的公开页面，不是官方 REST API。
- 应用使用浏览器登录态定时请求对战记录页，解析页面内嵌数据。
- 每场对局按 Replay ID 去重；会话根据对局时间和空闲周期自动切分。
- 轮询只抓取新增场次；启动时及运行中每小时完整核对一次 Buckler 最近历史，补齐分页边界或延迟上传导致的遗漏。
- Buckler 只公开最近约 100 场（最多 10 页）；完整核对和手动重扫都无法抓取更早的历史，超过该窗口的缺失只能从旧备份恢复。
- 同步时还会读取账号资料页的当前 LP/MR，作为分数快照保存。
- 对战详情中的对手段位仅在点击“查询 Buckler”或切换赛季时请求，使用资料页赛季列表和公开段位接口，结果在本机缓存 10 分钟。
- 手动会话默认在超过 3 小时没有新对局时自动重置，可在“会话历史”中调整为 0.5–24 小时。
- 所有数据保存在本机 SQLite 数据库中，不会上传到云端。

## 数据导出与备份

| 类型           | 用途                                                       |
| -------------- | ---------------------------------------------------------- |
| 对战记录 CSV   | 导出当前账号全部对局，便于 Excel 分析或长期归档            |
| 完整数据 JSON  | 导出账号、对局、分数点和会话，适合迁移或二次处理           |
| 恢复 JSON 备份 | 从本应用导出的 JSON 恢复数据；重复对局自动跳过，并重建会话 |
| 数据库备份     | 复制当前 SQLite 数据库，包含所有账号的完整本地数据         |

自动备份默认开启，每 24 小时执行一次，保存在应用数据目录的 `backups` 文件夹，最多保留 14 份。设置页可关闭自动备份或立即执行一次备份。升级到 `0.1.5` 时会先把旧数据库复制为 `backups/pre-migration-v1-*.db`，再执行主键与会话字段迁移。

## 数据与隐私

- 对局、分数和会话数据仅保存在本机。
- 登录态保存在 Electron 用户数据目录的 `session.json`，Chrome 登录配置保存在 `chrome-profile`。
- `session.json`、`chrome-profile` 和数据库文件包含敏感登录信息或个人数据，请勿公开分享。
- 删除账号会删除该账号的本地对局、分数点和会话数据。

## 已知限制

- Buckler 页面不是稳定 API，页面结构或访问策略变化可能导致同步失败。
- 数据更新存在轮询延迟，界面显示的是“准实时”而非游戏内实时数据。
- CAPCOM ID 登录态可能过期，需要重新登录。
- 较早的对局可能没有对手 LP 数据，此时详情页显示 `—`。
- 应用只读取公开页面数据，不读取游戏内存，也不与反作弊系统交互。
